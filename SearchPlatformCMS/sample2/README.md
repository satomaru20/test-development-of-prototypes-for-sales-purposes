# React + TypeScript 顧客管理サンプル(勉強用)
## セットアップ

Node.js 20.19+ または 22.12+ を推奨します（Vite 6 は Node.js 18+ をサポートします）。

```bash
npm install
npm run dev
```

表示されたローカルURL（通常は http://localhost:5173/）をブラウザで開いてください。

## 主な機能
- 顧客一覧、ステータス別件数
- 名前・会社名・メールアドレスでの検索
- ステータスによる絞り込み
- 顧客の新規登録、詳細表示、ステータス変更、削除
- レスポンシブ表示

データはReactの`useState`のみで保持し、ページ更新で初期化されます。実運用ではバックエンドAPIとDB接続が必要です。
