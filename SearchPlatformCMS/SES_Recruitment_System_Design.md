# 人材紹介／SES向けシステム 基本設計書・画面設計書

## システム概要
- Microsoft Graph による Outlook メール自動取込
- Azure AI Document Intelligence による文書解析
- Azure OpenAI による匿名化・スキル抽出・マッチング
- Azure AI Search によるベクトル検索
- Azure SQL Database によるデータ管理

## システム構成
```text
Outlook
 ↓
Microsoft Graph
 ↓
Azure Function
 ↓
Document Intelligence
 ↓
Azure OpenAI
 ↓
Azure SQL
 ↓
Azure AI Search
```
