# test-development-of-prototypes-for-sales-purposes
営業用プロトタイプ開発
* 履歴書情報内の個人情報自動マスキング・匿名化画面の作成
  * アップロードしたファイルやMicrosoft Outlookで来たメールに添付されているファイルや本文に記載されている履歴書情報を読み取り、個人情報の自動マスキング・匿名化を行う
  * 匿名化された履歴書情報をテキストファイルに格納する
  * 匿名化された履歴書情報のテキストファイルを読み取り、求職者情報としてDBに経歴・スキル情報の格納を行う
* 求人情報の個人情報自動マスキング・匿名化画面の作成
  * Microsoft Outlookで来たメールに添付されているファイルや本文に記載されている求人情報を読み取り、個人情報の自動マスキング・匿名化を行う
  * 匿名化された求人情報をテキストファイルに格納する
  * 匿名化された求人情報のテキストファイルを読み取り、DBに求人情報の格納を行う
* 求職者・求人情報管理画面
  * 管理者が各求職者、求人情報の情報を画面上で閲覧、編集、ステータス(未決定・決定・対象外)変更を行う
* 求人情報と求職者情報の相性マッチング画面
  * DBに格納された情報を求人情報と履歴書情報から情報の一致スコアを算出する
  * テータスが「未決定」の求職者の中から求人情報ごとに条件一致スコアが高い順に並べ、表示する
